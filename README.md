# 花靈物語（Fairy Garden）

用指令單指揮精靈的魔法自動化農場。單一 `index.html`，以 Chrome 開啟即可遊玩（目標解析度 1920×1080）。

- 第一章 中央魔法之花：藍圖建造、種植採收、乙太空間釀造花蜜、精靈指令單
- 第二章 擴充與維護：乙太空間擴充、元素轉化器、魔力收集結界、設施維護、第二朵魔法之花
- 第三章 流動通道：光之錨與高空通道、跨花加工鏈

精靈的指令單：動作（營造／收集／種植／運送／待命）＋物品＋範圍（預設 10 格），所有工作都以精靈的家為中心；「運送」另外選送往哪一朵魔法之花。新精靈預設「營造」：搬材料、施工，沒有藍圖時自動補滋養露與結界晶。
地格分地面層（花田、魔法之花）與低空層（結界、光之錨），同一格可各放一個；魔法之花所在的格子兩層都不能再蓋；光之錨可以蓋在水面上。
畫面有四個圖層：地面、低空、通道、居民（精靈），各自開關、可同時開多層，只有顯示中的圖層點得到。
每朵魔法之花的倉庫有一個上限值，每種物品各自和上限比較，可以花資源擴建。

召喚精靈需要魔法之花施法 10 秒；精靈平時停在自家花周圍的待機點，施工時會跳「精靈舞」。新種下的魔法之花建造費包含一隻精靈的召喚費，完工時直接從花中生出一隻精靈。音效以瀏覽器即時合成，上方工具列可以開關。

遊戲中按 P 鍵開關量測面板，顯示 FPS、每格畫面耗時、粒子數與畫布解析度。

進度存在瀏覽器 localStorage（存檔版本 5，舊版存檔不相容）。本遊戲的鍵名都以 `fairygarden.` 開頭，存檔裡附有遊戲名稱、用途說明與主頁網址。選單頁的「清空存檔」只刪除 `fairygarden.` 開頭的鍵，不影響同一個瀏覽器裡其他網站的資料。選單頁顯示版本更新時間。

之後預定的內容見 [ROADMAP.md](ROADMAP.md)。

## 測試

```bash
node --test tests/*.test.mjs        # 核心邏輯、指令單、倉庫、圖層、收益、邊界、三章可玩性模擬
node tests/mutation.mjs 120 1       # 變異測試：抽 120 個變異、門檻殺死率 0.8
node tests/smoke.mjs <截圖資料夾>     # 瀏覽器冒煙測試（需要 Playwright）
node tests/perf.mjs [寬x高]          # 繪圖量測：四個固定情境的每格繪圖指令數與耗時（需要 Playwright）
```
